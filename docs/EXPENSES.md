# المصاريف والرواتب في Odoo — دليل براء

## 1) إدخال مصروف (فاتورة مورد)

1. **المحاسبة ← الموردون ← الفواتير ← جديد.**
2. **اليومية: «المصاريف» (EXP)**. لا تستخدم «Purchases» (BILL)، فهي لبضاعة المشتريات، والسطر الذي يُترك فيها بلا حساب يذهب إلى تكلفة البضاعة 400001.
3. **المورد:** اسم المورد، أو **«مصروفات نقدية متنوعة»** للمصروف النقدي الذي بلا فاتورة ضريبية (محطة وقود، موقف، إصلاح صغير). الموردون المعتادون ضع لهم الوسم «مورد مصاريف».
4. **تاريخ الفاتورة:** يوم المصروف. Odoo يرفض أي تاريخ بعد اليوم بتوقيت الرياض. **المرجع:** رقم فاتورة المورد إن وُجد.
5. **سطر لكل نوع:** الوصف، و**الحساب** من الجدول أدناه، والمبلغ، و**الضرائب** حسب القسم 3. تأكد من عمود الضرائب في كل سطر قبل الترحيل.
6. **تأكيد** (ترحيل)، ثم **تسجيل دفعة**: يومية «كاش السائق» (CSHD) إن دُفع نقداً، أو «Bank» (BNK1) إن دُفع تحويلاً.

## 2) أي حساب لأي مصروف

| النوع | الحساب | أمثلة |
|---|---|---|
| رواتب وأجور | **400003** Basic Salary | القيد الشهري فقط (القسم 4)، لا تُدخل الرواتب يدوياً |
| وقود ونقل | **400077** Fuel | بنزين وديزل، أجرة نقل. صيانة السيارة تذهب إلى الصيانة |
| إيجار | **400017** Warehouse Rent | المستودع أو المحل. إيجار المكتب 400016، وإيجار السيارة 400074 |
| اتصالات واشتراكات | **400020** Telephone | جوال وإنترنت. الاشتراكات والبرامج (Odoo وواتساب API) على 400045 Subscriptions |
| صيانة | **400042** Maintenance | السيارات والثلاجات والمعدات |
| رسوم حكومية وتراخيص | **400032** Trade License Fees | البلدية والسجل التجاري والغرفة. رسوم الإقامات والتأشيرات 400014 |
| مصاريف بنكية | **400051** Other Bank Charges | عمولات التحويل ورسوم الحساب |
| مصاريف أخرى | **400028** Others | كل ما لا يدخل في غيره، وهو الحساب الافتراضي لليومية EXP |

## 3) ضريبة المدخلات: متى تُسجَّل

- **قبل 2026-10-01: لا ضريبة مدخلات على أي مصروف.** الشركة غير مسجلة في الضريبة قبل هذا التاريخ، فيُدخل المبلغ كاملاً وعمود الضرائب فارغ.
- **من 2026-10-01:** تُسجَّل الضريبة **فقط** إن كان بيدك فاتورة ضريبية فيها الرقم الضريبي للمورد والضريبة 15% ظاهرة (المبسّطة تكفي حتى 1000 ريال، وما فوقها يحتاج فاتورة كاملة باسم الشركة ورقمها الضريبي). اختر **«15% شامل (مشتريات)»** وأدخل المبلغ الإجمالي كما في الفاتورة، فيفصل Odoo الضريبة وحده.
- **بلا فاتورة ضريبية = بلا ضريبة مدخلات:** إيصال عادي، مورد غير مسجل، الرسوم الحكومية، الرواتب. **احذف أي ضريبة يقترحها Odoo على السطر.**

## 4) قيد الرواتب الشهري

1. عبّئ **«الراتب الشهري»** لكل موظف: **UTAK ← 🚚 التوصيل والفريق ← الموظفين**، في الحقل `x_monthly_salary`. الموظف الذي لا راتب له لا يدخل القيد (يظهر تحذير باسمه).
2. من مجلد المشروع، جرّب أولاً ثم رحّل:
   ```bash
   node scripts/payroll-monthly-entry.mjs 2026-09 --dry-run
   ```
   ```bash
   node scripts/payroll-monthly-entry.mjs 2026-09
   ```
3. الناتج قيد واحد في «المصاريف» بتاريخ آخر يوم في الشهر، أو اليوم إن كان الشهر لم ينتهِ. في القيد سطر مدين على **400003** لكل موظف باسمه، وسطر دائن بالمجموع على **201004 مستحقات الرواتب**. التشغيل الثاني لنفس الشهر لا ينشئ شيئاً (المرجع `UTAK-PAYROLL-YYYY-MM`). لإعادة شهر: أعد القيد إلى مسودة ثم ألغه، ثم شغّل السكربت من جديد. السكربت لا يعمل تلقائياً أبداً.

## 5) صرف الرواتب (يُقفل المستحق)

**المحاسبة ← القيود اليومية ← جديد:**
- **اليومية:** «كاش السائق» (CSHD) للصرف النقدي، أو «Bank» (BNK1) للتحويل.
- **مدين 201004** بمبلغ الراتب، والشريك هو الموظف.
- **دائن 101007** (كاش السائق) أو **101001** (Bank) بالمبلغ نفسه.
- رحّل. بعد صرف رواتب الشهر كلها يعود رصيد 201004 إلى صفر، وأي رصيد باقٍ فيه هو رواتب لم تُصرف بعد.
